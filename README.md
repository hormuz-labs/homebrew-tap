# Hormuz Labs Homebrew tap

```bash
brew install hormuz-labs/tap/manul
brew install hormuz-labs/tap/outreach
```

- [Manul](https://github.com/hormuz-labs/manul): drop in a video, say what you want, and it does the edit.
- [Outreach](https://github.com/hormuz-labs/outreach-releases): find Instagram leads, qualify them with Gemini, and DM them from your team's accounts.

Each cask follows its app's GitHub releases automatically.
